Política de Privacidad — WeatherAlert

Última actualización: Mayo 2026

WeatherAlert es una aplicación de meteorología desarrollada por David SF. Esta política explica qué datos se recopilan y cómo se utilizan.

Datos que recopilamos

  • Ubicación: Usamos tu ubicación para obtener el tiempo local. Solo se accede cuando la app está en uso y nunca se almacena en servidores externos.
  • Preferencias: Las alertas y ajustes se guardan localmente en tu dispositivo (AsyncStorage). No se envían a ningún servidor.

Datos que NO recopilamos

  • No recopilamos nombre, email ni ningún dato personal identificable.
  • No compartimos datos con terceros salvo la API de meteorología (Visual Crossing), que recibe únicamente las coordenadas GPS para devolver el tiempo.
  • No usamos publicidad ni rastreadores.

Servicios de terceros

WeatherAlert utiliza Visual Crossing Weather API para obtener datos meteorológicos. Solo se envían coordenadas de ubicación, sin datos personales.

Permisos

  • Ubicación: Necesaria para mostrar el tiempo de tu zona.
  • Notificaciones: Necesarias para enviarte alertas meteorológicas. Puedes desactivarlas en cualquier momento desde los ajustes del sistema.
